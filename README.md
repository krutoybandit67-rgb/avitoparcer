# Avito Smart Finder

Telegram-бот для поиска объявлений о смартфонах до 1 000 ₽, анализа текста/фото через Gemini и отправки карточки с фото и ссылкой в Telegram.

## Важно о поиске объявлений

В этой стартовой версии используется API.SH как сторонний поставщик данных Avito, а не официальный API Avito.
Документация провайдера: https://api.sh/docs/avito-search

По документации один поиск стоит 5 credits. Сейчас выполняются 4 поисковых запроса (Россия и Рязань, слова «смартфон» и «телефон») на каждом цикле, то есть минимум 20 credits за цикл при одной странице на запрос. Учитывайте стоимость и лимиты аккаунта API.SH.

Официальный Avito Business API не является универсальным публичным поиском чужих объявлений; его доступные методы в основном работают с аккаунтом владельца. Проверьте условия и доступность провайдера до пополнения баланса.

## Функции

- Максимальная цена 1 000 ₽.
- Поиск по России и отдельный запрос по Рязани.
- Фото объявления отправляется в Telegram; дополнительные фото отправляются альбомом.
- Ссылка на оригинальное объявление.
- Gemini анализирует описание и до 3 фото.
- Оценка риска, сложности и ориентировочной стоимости ремонта.
- PostgreSQL не даёт присылать одно объявление повторно.
- `/start`, `/status`, `/scan`.

## Деплой

1. Создайте приватный GitHub-репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. В Railway создайте проект `Deploy from GitHub repo` и выберите репозиторий.
4. Добавьте PostgreSQL в Railway. Railway обычно предоставляет `DATABASE_URL`; подключите его как переменную сервиса бота.
5. Добавьте Variables:
   - `BOT_TOKEN`
   - `GEMINI_API_KEY`
   - `APISH_KEY`
   - `ADMIN_CHAT_ID`
   - `MAX_PRICE=1000`
   - `POLL_MINUTES=45`
   - `PAGES_PER_QUERY=1`
6. Нажмите Deploy. Откройте Telegram и отправьте боту `/start`, затем `/scan`.

## Как узнать ADMIN_CHAT_ID

После первого запуска отправьте боту `/start`. Для получения числового chat ID можно временно посмотреть логи, либо использовать безопасный Telegram-бот для отображения собственного ID. Не публикуйте ID и токены в открытом репозитории.

## Ограничения первой версии

- «Все объявления» означает все результаты, которые провайдер отдаёт на выбранных страницах и по заданным запросам; это не гарантия полного архива всех объявлений Avito. Увеличение `PAGES_PER_QUERY` увеличит охват и расход credits.
- Поиск по Рязани и России может возвращать пересекающиеся результаты; дубликаты убираются по ID.
- Рыночная цена исправного устройства не определяется достоверно без отдельной выборки сопоставимых проданных/активных устройств. Gemini может вернуть `null`, если данных недостаточно.
- Оценка по фото не заменяет диагностику. Перед покупкой проверяйте IMEI/блокировки, аккаунты, связь, зарядку, экран и документы.
- Сначала протестируйте `/scan` вручную. Не увеличивайте частоту и страницы, пока не проверите расход API.SH.
